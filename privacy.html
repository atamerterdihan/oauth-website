Privacy Policy

Last updated: 9 November 2026

AI Is Arama V2 - Gmail is a personal, single-user integration. It requests only the https://www.googleapis.com/auth/gmail.readonly permission.

Google user data accessed

The integration may access message identifiers, sender and recipient information, dates, subjects, labels, snippets, and the body of recruitment or job-application messages when needed for matching and status review. Attachment content is not part of the current integration.

How data is used

Data is used only to identify recruitment messages and associate them with the owner's local job-application records. The integration does not use Gmail data for advertising, profiling, resale, or any unrelated purpose.

Storage and sharing

OAuth credentials are stored locally with restricted file permissions outside the project repository. Minimized matching evidence may be stored locally. Google user data is not sold or shared with third parties.

Security and control

Access is read-only. The account owner can revoke access at any time from the Google Account security settings. The integration is designed to stop safely if authorization is missing or invalid.

Contact

For privacy questions, use the support email displayed on the Google OAuth consent screen. No separate public contact address is published on this draft page.
