AI Is Arama V2 - Gmail

AI Is Arama V2 is a private, non-commercial job-search assistant operated by its owner on a personal Raspberry Pi. It uses the Gmail API only to read recruitment and job-application messages for the owner's own account.

What the integration does

  • Searches for recruitment and job-application messages.
  • Reads message headers and, only when necessary, message content.
  • Matches relevant messages to the owner's local application records.

What it does not do

  • It does not send, draft, reply to, forward, label, archive, or delete email.
  • It does not provide public accounts or public sign-up.
  • It does not sell or share Google user data.
